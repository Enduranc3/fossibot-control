# Fossibot Control

Неофіційний застосунок для зарядних станцій **Fossibot F1800 / F3000**: моніторинг і керування без
офіційного застосунку. Два способи підключення:

| Режим | Як працює | Коли використовувати |
|---|---|---|
| **Wi-Fi станції** | iPhone підключається до мережі `FOSS_<SN>`, застосунок відкриває TCP-порт 8058, станція підключається до телефона | Без інтернету: у полі, під час відключень світла |
| **Сервер** | Вхід в акаунт Fossibot, дані через `app.fossibot.hk` | Станція в домашньому Wi-Fi, телефон будь-де |

Протокол розібрано з офіційного застосунку, див. [PROTOCOL.md](PROTOCOL.md).
Проєкт не пов'язаний із Fossibot.

## Можливості

- Кругова діаграма заряду (зелений → жовтий → червоний), стан «Заряджання / Розряджання / Очікування»
- Вхідна та вихідна потужність із розбивкою (AC, сонце/DC, USB), час до повного заряду чи розряду
- Тумблери AC 220V, DC 12V, USB, ліхтар (постійно / SOS / стробоскоп)
- Налаштування станції: UPS/ECO, потужність заряджання, ліміти заряду й розряду, струм DC, яскравість, тайм-аути
- Консоль налагодження з сирими HEX-пакетами (TX/RX) і ручним відправленням команд
- Автоперепідключення, запам'ятовування останнього підключення, пароль у Keychain

## Встановлення на iPhone (SideStore, безкоштовний Apple ID)

Одноразове налаштування, потрібні Mac і кабель.

1. На iPhone встановіть **LocalDevVPN** з App Store.
2. На Mac встановіть **iloader** (<https://github.com/nab138/iloader>, розділ Releases).
3. Підключіть iPhone кабелем і натисніть «Довіряти цьому комп'ютеру».
4. В iloader увійдіть з Apple ID і натисніть **Install SideStore (Stable)**.
   Краще використати окремий безкоштовний Apple ID.
5. На iPhone відкрийте **Параметри → Загальні → VPN і керування пристроєм** і довіртеся сертифікату розробника.
6. Відкрийте **Параметри → Приватність і безпека → Режим розробника**, увімкніть його і перезавантажте телефон.
7. Відкрийте SideStore, увімкніть LocalDevVPN, зайдіть у **Sources → +** і додайте:
   ```
   https://github.com/Enduranc3/fossibot-control/releases/latest/download/source.json
   ```
8. Встановіть **Fossibot Control** зі списку.

Далі:
- Підпис діє 7 днів. SideStore продовжує його сам: потрібні інтернет і ввімкнений LocalDevVPN.
  Для надійності можна створити в «Командах» автоматизацію, наприклад «щоночі на зарядці → оновити SideStore».
- Нова версія застосунку з'являється в SideStore після кожного релізу (див. нижче).
- Ліміт безкоштовного Apple ID — 3 застосунки, включно із самим SideStore.
- Режим розробника має лишатися ввімкненим.
- Після великих оновлень iOS може знадобитися заново згенерувати pairing file через iloader.

## Використання

**Wi-Fi станції**
1. Параметри → Wi-Fi → мережа `FOSS_…` вашої станції.
2. Застосунок → «Підключення» → «Wi-Fi станції» → «Підключитися».
3. Під час першого запуску дозвольте доступ до **локальної мережі**.

Якщо станція не підключається, відкрийте консоль унизу: там видно IP-адресу телефона і все, що приходить.

**Сервер**: «Підключення» → «Сервер», увійдіть з email і паролем від застосунку Fossibot та виберіть станцію.

Застосунок працює, лише поки відкритий на екрані: у фоні iOS присипляє мережеві з'єднання.

## Збірка та релізи

Збирає GitHub Actions (`.github/workflows/ios.yml`) на `macos-26`, Xcode на Mac не потрібен.

- Push у `main`: тести і непідписаний IPA як артефакт workflow.
- Тег `v*`: GitHub Release з `FossibotControl.ipa` і `source.json` для SideStore.

```bash
git tag v1.0.1 && git push origin v1.0.1
```

Репозиторій має бути **публічним**: SideStore завантажує IPA за прямим посиланням, а macOS-збірки
в публічних репозиторіях безкоштовні.

## Розробка

```bash
npm install
npm run dev        # http://localhost:5173/?demo — демо-станція в браузері
npm test           # тести протоколу (CRC, кодування команд, розбір пакетів)
npm run build && npx cap sync ios
```

Структура:
- `src/protocol.ts` — кодек протоколу
- `src/fossibot-driver.ts` — драйвер (стан, команди, телеметрія)
- `src/transports.ts` — транспорти: TCP-сервер, хмара, демо
- `src/cloud-api.ts` — HTTP API Fossibot
- `plugins/fossibot-net` — нативний Swift-модуль: TCP-сервер (Network.framework), WebSocket із заголовками, Keychain

## Home Assistant

`ha_bridge.py` публікує телеметрію і приймає команди через MQTT Auto-Discovery: сенсори, перемикачі AC/DC/USB,
вибір режиму LED і UPS/ECO, числові налаштування.

```bash
pip install "paho-mqtt>=2" "websockets>=14"
# через сервер Fossibot (станція в домашньому Wi-Fi):
FOSSIBOT_PASSWORD='…' python3 ha_bridge.py cloud --user you@example.com --sn F1800XXXX --mqtt-host 192.168.1.10
# локально (хост підключений до Wi-Fi станції FOSS_…):
python3 ha_bridge.py local --sn F1800XXXX --mqtt-host 192.168.1.10
```
